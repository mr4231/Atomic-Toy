# Team Roles

The project follows the six-stream plan supplied with the assignment. Assign names and roll numbers before submission.

| Stream | Owner | Code and evidence responsibility |
|---|---|---|
| M1 | Team lead | Integration, tests, reproducibility, final recommendation |
| M2 | Physics | Geometry, cutoff neighbors, pair forces, hard walls |
| M3 | Numerical methods | Euler/Verlet, K/U/E, timestep study |
| M4 | Dissipation and precision | Drag, relaxation criterion, float32/float64 comparison |
| M5 | Performance | Python/NumPy/C parity, timings, memory table |
| M6 | Visualisation and innovation | 3D animation, diagnostics, measured innovation |

Each result should name the script, configuration, seed, Git commit, and owner that produced it.
